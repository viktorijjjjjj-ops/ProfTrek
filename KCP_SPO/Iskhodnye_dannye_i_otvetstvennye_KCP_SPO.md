# Исходные данные, участники и ответственные лица проекта «КЦП СПО»

## 1. Назначение документа

Документ задает стартовый состав данных, участников и зон ответственности для региональной кампании формирования и согласования КЦП СПО. ФИО ответственных лиц заполняются заказчиком после официального назначения. До назначения используются должности и организации.

## 2. Паспорт участников проекта

| Код | Участник | Организация | Ответственная роль | Основная функция | Статус назначения |
|---|---|---|---|---|---|
| REG-01 | Региональный заказчик | Региональный орган управления образованием | Руководитель проекта | Утверждает цели, регламент, методику и итоговый свод КЦП | Назначить ФИО |
| REG-02 | Владелец процесса | Региональный орган управления образованием | Руководитель кампании КЦП | Организует ежегодный цикл, сроки и межведомственное взаимодействие | Назначить ФИО |
| REG-03 | Оператор платформы | Региональный проектный офис / подведомственная организация | Администратор платформы | Управляет ролями, справочниками, доступами и поддержкой | Назначить ФИО |
| REG-04 | Аналитический центр | Региональный орган управления образованием | Региональный аналитик | Рассчитывает востребованность, готовит свод и сценарии КЦП | Назначить ФИО |
| REG-05 | Центр занятости | Региональная служба занятости населения | Ответственный за данные рынка труда | Передает вакансии, дефицит, напряженность и прогноз занятости | Назначить ФИО |
| REG-06 | Работодатель | Крупные предприятия и объединения работодателей региона | Представитель работодателя | Подтверждает потребность по профессиям, территориям и срокам | Назначить по каждой организации |
| REG-07 | ПОО | Профессиональная образовательная организация | Руководитель ПОО | Утверждает предложение по объемам и структуре приема | Назначить ФИО |

| REG-09 | Отраслевой блок | Региональный орган исполнительной власти по отрасли | Отраслевой эксперт | Проверяет приоритетность профессий и прогноз отрасли | Назначить ФИО |

| REG-11 | Межведомственный штаб | Представители органов власти, службы занятости, работодателей и ПОО | Председатель штаба | Рассматривает расхождения и рекомендует вариант свода | Назначить ФИО |
| REG-12 | Секретарь штаба | Орган управления образованием | Секретарь заседания | Формирует повестку, протокол и контроль поручений | Назначить ФИО |

## 3. Карточка ответственного лица

Для каждой назначенной персоны в системе заполняются:

| Поле | Обязательность |
|---|---|
| Фамилия, имя, отчество | Обязательно |
| Должность | Обязательно |
| Организация и подразделение | Обязательно |
| Роль в платформе | Обязательно |
| Рабочий телефон | Обязательно для координаторов |
| Электронная почта | Обязательно |
| Замещающее лицо | Обязательно для ключевых ролей |
| Период полномочий | Обязательно |
| Основание назначения | Приказ / распоряжение / протокол |

## 6. Матрица ответственности RACI

Обозначения: **R** — выполняет работу, **A** — утверждает результат, **C** — консультирует, **I** — получает информацию.

| Процесс | Заказчик | Кампания | ЦЗН | Работодатель | ПОО | Аналитик | Эксперт / штаб |
|---|---|---|---|---|---|---|---|
| Утверждение методики | A | R | C | C | C | R | C |
| Сбор кадровых заявок | I | A | C | R | I | R | I |
| Передача данных рынка труда | I | A | R | C | I | R | I |
| Подача предложения КЦП | I | A | I | C | R | C | I |
| Расчет востребованности | I | A | C | C | C | R | C |
| Формальная проверка | I | A | C | I | R | R | I |
| Отраслевая экспертиза | I | C | C | C | C | R | A |
| Формирование свода | A | R | C | C | C | R | C |
| Межведомственное согласование | A | R | C | C | C | R | A |
| Утверждение КЦП | A | R | I | I | I | C | C |
| Мониторинг исполнения | A | R | R | C | R | R | I |

## 7. Правила актуализации

1. Владелец набора данных отвечает за его полноту, актуальность и источник.
2. Каждая загрузка получает дату, версию, период данных и отметку о проверке.
3. Исправления после подачи заявки выполняются только через новую версию с указанием причины.
4. Не подтвержденные работодателем данные маркируются как предварительные.
5. Персональные данные ответственных лиц доступны только пользователям с соответствующим правом.
6. Перед запуском официальной кампании демонстрационные значения удаляются или помечаются как тестовые.
