# Паспорт регионального проекта «КЦП СПО»

| Параметр | Содержание |
|---|---|
| Наименование | Региональная межведомственная платформа формирования и согласования КЦП СПО |
| Рабочее название | «КЦП СПО: региональный кадровый контур» |
| Тип проекта | Региональный цифровой управленческий проект |
| Инициатор | Уполномоченный орган управления образованием субъекта Российской Федерации |
| Заказчик | Региональный орган исполнительной власти, отвечающий за СПО и кадровое развитие |
| Межведомственные участники | Центры занятости населения, работодатели, объединения работодателей, ПОО, отраслевые органы региона |
| Проблема | Нет единой синхронизации спроса на профессии, предложений ПОО и объемов КЦП |
| Цель | Согласовать структуру и объемы КЦП с реальной и прогнозной потребностью экономики муниципалитетов и региона |
| Объект автоматизации | Кадровый спрос, востребованность профессий, предложения ПОО, расчет, экспертиза, согласование и мониторинг КЦП |
| География | Весь субъект Российской Федерации: муниципалитеты, отрасли и ПОО региона |
| Срок | 12 месяцев до промышленного запуска, далее постоянный ежегодный цикл |
| Продукт | Региональная веб-платформа с кабинетами ведомств, работодателей, центров занятости и ПОО |
| Пилот | Не менее 5 муниципалитетов, 3 отраслей, 10 ПОО, 30 работодателей и 1 цикл КЦП |
| Ответственный заказчик | Руководитель проекта от регионального органа управления образованием; ФИО назначается приказом |
| Координатор кампании | Руководитель кампании КЦП; ФИО назначается приказом |
| Оператор платформы | Региональный проектный офис / подведомственная организация; ФИО назначается распоряжением |
| Ответственный за данные рынка труда | Представитель региональной службы занятости населения; ФИО назначается письмом |
| Ответственные в ПОО | Руководитель ПОО и координатор КЦП ПОО; назначаются приказом по каждой организации |
| Коллегиальный орган | Региональный межведомственный штаб; состав утверждается распоряжением |

## Задачи

1. Утвердить региональную методику оценки востребованности профессий.
2. Объединить данные работодателей, центров занятости и ПОО.
3. Рассчитать индекс востребованности и карту кадрового дефицита.
4. Синхронизировать предложения ПОО с потребностью по территориям и отраслям.
5. Автоматизировать проверки, экспертизу, согласование и протоколирование.
6. Обеспечить межведомственное рассмотрение сценариев КЦП.
7. Связать утвержденные цифры с мониторингом набора, выпуска и трудоустройства.

| Заявки ПОО в цифровом контуре | 100% пилота |
| Объемы КЦП с кадровым обоснованием | не менее 90% |
| Решения с межведомственным протоколом | 100% |
| Сокращение срока свода | не менее 30% |

## Принципы

Региональность, межведомственность, доказательность, единые справочники, территориальный баланс, персональная ответственность, версионность решений и ежегодная обратная связь по фактическому трудоустройству.

## Участники и исходные данные

Подробный реестр участников, должностей, контактных полей, источников данных и матрица ответственности RACI приведены в документе `Iskhodnye_dannye_i_otvetstvennye_KCP_SPO.md`. Стартовый машинный набор для загрузки в прототип находится в файле `Iskhodnye_dannye_KCP_SPO.json`.

В состав стартовых данных входят справочники муниципалитетов, отраслей, профессий и ПОО; кадровые заявки работодателей; сведения центров занятости о вакансиях и дефиците; данные о мощности, приеме, выпуске и трудоустройстве ПОО; прогнозы отраслевого развития; лимиты и решения межведомственного штаба.

## Границы

Платформа формирует аналитическое и согласовательное основание для КЦП. Она не подменяет нормативный акт, полномочия органа управления образованием, деятельность службы занятости, кадровые решения работодателя или образовательный процесс ПОО.

## Основные риски

| Риск | Мера |
|---|---|
| Несопоставимые данные ведомств | единые классификаторы, регламент обмена и владелец каждого набора данных |
| Низкая активность работодателей | отраслевые объединения, личные кабинеты и подтверждение заявок |
| Конфликт регионального и муниципального приоритета | сценарии, прозрачные критерии и межведомственный штаб |
| Устаревание прогноза | ежеквартальное обновление спроса и ежегодный пересмотр методики |
| Утечка информации | минимизация данных, RBAC, аудит, резервное копирование и регламент доступа |
