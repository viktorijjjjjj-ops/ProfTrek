# КЦП СПО

Цифровая платформа для формирования и согласования контрольных цифр приема по программам среднего профессионального образования.

## Состав проекта

- `index.html` — демонстрационный веб-прототип платформы.
- `assistant.html` — цифровой помощник органа управления образованием.
- `Opisanie_platformy_KCP_SPO.md` — описание решения.
- `Pasport_proekta_KCP_SPO.md` — паспорт проекта.
- `Doklad_KCP_SPO.md` — текст доклада для защиты.
- `Prezentaciya_KCP_SPO.md` — содержание презентации по слайдам.
- `build_documents.py` — генератор DOCX и PPTX из материалов проекта.
- `Iskhodnye_dannye_i_otvetstvennye_KCP_SPO.md` — реестр участников, исходных данных и матрица ответственности.
- `Iskhodnye_dannye_KCP_SPO.json` — стартовый демонстрационный набор для загрузки в прототип.
- `Opisanie_cifrovogo_pomoshchnika_KCP_SPO.md` — функции, сценарии и ограничения помощника.

## Быстрый запуск

Откройте `index.html` в браузере. Прототип работает без сервера и сохраняет тестовые изменения в `localStorage`.

Откройте `assistant.html`, чтобы запустить цифрового помощника органа управления образованием. Он работает в демо-режиме на стартовом наборе данных и формирует аналитические рекомендации, поручения и черновик протокола.

Для формирования документов при наличии Python и пакетов `python-docx`, `python-pptx` выполните:

```bash
python build_documents.py
```

Перед официальным использованием необходимо заменить демонстрационные показатели, настроить нормативные справочники, ролевую модель, интеграции и требования к персональным данным.
